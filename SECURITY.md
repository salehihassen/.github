# Security Policy

Thanks for helping keep this project and its users safe.

## Reporting a vulnerability

Please **don't** open a public issue, pull request, or discussion for a security problem.

Report it privately instead:

1. **GitHub:** open the repository's **Security** tab and click **Report a vulnerability**. This is the preferred route when the button is available.
2. **Email:** send the details to **security@salehh.xyz**.

Helpful details to include:

- the affected repository and version or commit
- what the issue is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- any suggested fix

## What to expect

I maintain these projects on my own, so I can't promise a fixed response time. I read every report and will reply as soon as I can. Please give me a reasonable chance to fix the issue before you disclose it publicly. Reporters who want credit will get it once the fix is released.

## Supported versions

Unless a repository says otherwise, only the latest code on the default branch gets security fixes.
